### Key Insight
Merge Sort:
  split → sort each half → merge
  guaranteed O(n log n) always

Sort Colors:
  three pointers — low, mid, high
  0 → swap with low
  1 → just move mid
  2 → swap with high

Merge Intervals:
  sort by start first!
  overlap = current start <= previous end
  merge = extend previous end
